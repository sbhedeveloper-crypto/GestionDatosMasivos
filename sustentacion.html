🆔 Definición de id_registro

id_registro = SHA256(país + indicador + fecha)[:16]

Garantiza unicidad al combinar país (ISO 3166-1), indicador y año, evitando duplicados al reejecutar la ingesta.

⚡ ¿Lambda o Kappa?

Tipo Kappa.

  • Un solo flujo unificado: API → JSONL (raw) → CSV (servicio) → Streamlit.
  • No hay dos pipelines paralelos (batch + speed).
  • Los JSONL en datos/raw/ actúan como registro inmutable de entrada.
  • El reprocesamiento se logra reejecutando ingest.py sobre el mismo rango de fechas.

4 · Componente: Ingesta (Fase 1)

Diapositiva 5 de 8
src/ingest.py
src/ingest.py
Descarga indicadores macroeconómicos de la API del Banco Mundial con paginación, reintentos automáticos y filtrado local por rango de fechas. Calcula id_registro para evitar duplicados y escribe JSONL particionado por fecha_ingesta=AAAA-MM-DD.

Flujo de ejecución

  1. Itera sobre 49 países × 10 indicadores (inflación, desempleo, PIB, población, esperanza de vida, comercio, tipo de cambio, remesas, CO₂).
  2. Para cada combinación, consulta la API con paginación ($limit, $offset).
  3. Si hay timeout, reintenta automáticamente hasta 5 veces con retroceso exponencial.
  4. Filtra por rango de fechas localmente (evita errores 400 del servidor).
  5. Escribe JSONL en carpetas particionadas y genera un manifiesto JSON por ejecución.

5 · Componentes: Curado, Tablero y Servicio (Fases 2-4)

Diapositiva 6 de 8
src/spark_curar.py
src/spark_curar.py
Limpia los JSONL con PySpark: elimina nulos, elimina duplicados por id_registro, valida esquema y ordena por fecha. Compara estilo MapReduce (RDD) vs DataFrame API.
src/generar_tablero.py
src/generar_tablero.py
Lee todos los JSONL de la zona raw, los normaliza a DataFrame y genera indicadores_servicio.csv y indicadores_agregados.json para el tablero. No requiere PostgreSQL.
app/streamlit_app.py
app/streamlit_app.py
Tablero interactivo que lee el CSV de servicio. Incluye filtros por indicador, país y fecha; gráficos de series temporales (Plotly), barras de promedio por país, tabla detallada y botón 🔄 Refrescar datos que limpia el caché y recarga sin recargar la página.

Resultado en el tablero

  • 64,215 registros disponibles en el CSV de servicio.
  • 1,117 filas de agregados por país, indicador, año y mes.
  • Ejecutar con: python -m streamlit run app/streamlit_app.py --server.port 8502
  • Acceder en: http://localhost:8502

⚠️ Limitaciones conocidas

  • Streamlit no tiene "push" nativo; el botón Refrescar datos recarga manualmente.
  • Para tiempo real verdadero se necesitaría consumidor Kafka continuo + base de datos remota.
  • Los JSONL de zona raw no se suben a GitHub por tamaño; se regeneran con la ingesta.
